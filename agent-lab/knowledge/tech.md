# Tecnologias do acervo do Marcos

## Automação e agentes
- n8n — automação de fluxos e integrações entre sistemas (projetos de agentes e automações).
- Python — scripts, automações e desenvolvimento de agentes de IA.
- JavaScript / Node.js — scripts, back-end e automações.
- Ollama — execução local de modelos de linguagem para experimentação com IA.

## Infraestrutura
- Proxmox — virtualização de servidores e gerenciamento de VMs.
- Linux / Debian — sistemas operacionais para servidores e produção.
- Docker — containerização de aplicações.
- Raspberry Pi — computação de baixo custo para automação e IoT.
- Home Assistant — automação integrando dispositivos IoT.
- MQTT — mensageria leve para IoT.
- Synology — armazenamento em rede (NAS) para backups e serviços locais.
- Ubiquiti — equipamentos de rede para infra doméstica e profissional.
- Cloudflare — rede de borda e segurança, tunnel para expor serviços internos.

## Web
- Next.js — framework React com renderização no servidor.
- React — construção de interfaces web modernas e reativas.
- Tailwind CSS — estilos utilitários para interfaces consistentes.
- TypeScript — tipagem estática para JavaScript.
- PHP — back-end e scripts server-side.

## Dados e serviços
- PostgreSQL — banco relacional para aplicações robustas.
- Supabase — backend-as-a-service com banco e autenticação.
- Redis — cache e armazenamento em memória de alta performance.
- Metabase — dashboards e visualização de dados.

## Ferramentas de trabalho
- Git — controle de versão.
- GitLab — versionamento e CI/CD.
- Slack — comunicação e integração de times via automações e bots.
